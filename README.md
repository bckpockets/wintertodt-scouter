# Wintertodt Scouter

Rebuilding the RuneLite Wintertodt Scouter under bckpockets, based on Nouser/nucleon's BSD-licensed plugin.

Development is in progress. This repository is not yet a released or approved Plugin Hub replacement.

The rebuild addresses stale observations, service failures, current RuneLite APIs, reliable manual hopping, world discovery, regression tests, and a maintainable crowdsourcing service.

Original project: https://github.com/Nouser/wintertodt-scouter
